# 移动端对话布局实现思路

## 概述

本文档描述了一个响应式聊天界面的核心实现思路，该布局在**桌面端**同时显示对话列表和对话详情，在**移动端**则通过"列表 → 详情"的页面切换方式展示。

## 核心设计思路

### 1. 双状态管理

使用两个独立的状态变量分别控制桌面端和移动端的视图：

```typescript
// 桌面端：始终控制当前选中的对话，用于显示右侧详情内容
const selectedUser = ref<ChatUser | null>(null)

// 移动端：专门控制是否显示详情页（覆盖全屏）
const mobileSelectedUser = ref<ChatUser | null>(null)
```

**为什么需要两个状态？**
- `selectedUser`：桌面端始终需要知道当前选中了谁，用于渲染右侧详情内容
- `mobileSelectedUser`：移动端需要一个独立状态来控制详情页是否覆盖显示
- 分开处理可以避免桌面端和移动端互相干扰

### 2. 点击对话时的处理

当用户点击对话列表中的某一项时，同时设置两个状态：

```typescript
function handleSelectUser(chatUser: ChatUser) {
  selectedUser.value = chatUser        // 桌面端：更新详情内容
  mobileSelectedUser.value = chatUser  // 移动端：触发详情页显示
}
```

### 3. CSS 响应式布局策略

#### 左侧对话列表

```css
/* 基础样式：移动端全宽 */
.chat-list {
  width: 100%;
}

/* 桌面端：固定宽度侧边栏 */
@media (min-width: 640px) {
  .chat-list {
    width: 224px; /* sm:w-56 */
  }
}

@media (min-width: 1024px) {
  .chat-list {
    width: 288px; /* lg:w-72 */
  }
}
```

#### 右侧详情区域（核心）

```css
.chat-detail {
  /* 移动端默认：绝对定位，隐藏在视口右侧 */
  position: absolute;
  inset: 0;
  inset-inline-start: 100%;  /* 初始位置在视口右外侧 */
  z-index: 50;
  display: none;             /* 默认隐藏 */
  width: 100%;
  
  /* 桌面端：静态定位，始终显示 */
  @media (min-width: 640px) {
    position: static;
    z-index: auto;
    display: flex;
  }
}

/* 移动端选中状态：滑入显示 */
.chat-detail.is-mobile-active {
  inset-inline-start: 0;     /* 从右侧滑入到视口内 */
  display: flex;
}
```

**关键点解析：**

| 状态 | 定位方式 | 显示逻辑 |
|------|----------|----------|
| 移动端未选中 | `absolute` + `start: 100%` + `hidden` | 在视口右侧外部，不可见 |
| 移动端已选中 | `absolute` + `start: 0` + `flex` | 覆盖全屏显示 |
| 桌面端 | `static` + `flex` | 始终作为侧边栏显示 |

### 4. 返回按钮的实现

在详情页顶部添加返回按钮，**仅在移动端显示**：

```vue
<template>
  <!-- 返回按钮：sm:hidden 表示桌面端隐藏 -->
  <button 
    class="sm:hidden" 
    @click="mobileSelectedUser = null"
  >
    <ArrowLeftIcon />
  </button>
</template>
```

```typescript
function handleBack() {
  // 只清空移动端状态，不影响桌面端的 selectedUser
  mobileSelectedUser.value = null
  // 效果：详情页滑出，回到对话列表
}
```

## 交互流程图

### 移动端

```
┌─────────────────┐      点击对话项       ┌─────────────────┐
│                 │  ─────────────────→  │                 │
│   对话列表页     │   selectedUser = user │   对话详情页     │
│                 │   mobileSelectedUser  │   (全屏覆盖)     │
│  ┌───────────┐  │      = user           │                 │
│  │ 用户 A    │  │                      │  ┌───────────┐   │
│  │ 用户 B    │  │                      │  │ ← 返回     │   │
│  │ 用户 C ✓  │  │  ←─────────────────  │  │           │   │
│  └───────────┘  │   点击返回按钮         │  │ 消息内容   │   │
│                 │   mobileSelectedUser  │  └───────────┘   │
│                 │      = null           │                 │
└─────────────────┘                      └─────────────────┘
```

### 桌面端

```
┌──────────┬─────────────────────────────┐
│          │                             │
│ 对话列表  │        对话详情区域           │
│          │        (始终显示)            │
│ 用户 A   │                             │
│ 用户 B ✓ │    选中用户 B 的消息内容       │
│ 用户 C   │                             │
│          │                             │
└──────────┴─────────────────────────────┘
   ↑
   └── 点击切换用户，只更新 selectedUser，详情区域内容变化
```

## 适配到 Vue + shadcn 的注意事项

### 1. 状态管理

Vue 中使用 `ref` 替代 React 的 `useState`：

```vue
<script setup lang="ts">
import { ref } from 'vue'

const selectedUser = ref<ChatUser | null>(null)
const mobileSelectedUser = ref<ChatUser | null>(null)
</script>
```

### 2. 条件类名绑定

使用 Vue 的 `:class` 绑定动态类名：

```vue
<template>
  <div 
    :class="[
      'absolute inset-0 start-full z-50 hidden w-full flex-1 flex-col border bg-background shadow-xs',
      'sm:static sm:z-auto sm:flex sm:rounded-md',
      mobileSelectedUser && 'inset-s-0 flex'
    ]"
  >
    <!-- 详情内容 -->
  </div>
</template>
```

### 3. shadcn 组件对应

| 功能 | React 版本 | Vue shadcn 对应 |
|------|-----------|----------------|
| 按钮 | `<Button>` | `<Button>` |
| 头像 | `<Avatar>` | `<Avatar>` |
| 滚动区域 | `<ScrollArea>` | `<ScrollArea>` |
| 分隔线 | `<Separator>` | `<Separator>` |
| 对话框 | `<Dialog>` | `<Dialog>` |

### 4. 工具函数

```typescript
// 使用 clsx / tailwind-merge 处理类名
import { cn } from '@/lib/utils'

// 或使用 Vue 的计算属性
const detailClasses = computed(() => {
  return cn(
    'absolute inset-0 start-full z-50 hidden w-full flex-1 flex-col',
    'sm:static sm:z-auto sm:flex',
    mobileSelectedUser.value && 'inset-s-0 flex'
  )
})
```

## 关键 CSS 类名说明

```
absolute inset-0          → 绝对定位，覆盖整个父容器
start-full                → 逻辑属性，初始位置在右侧外部（支持 RTL）
z-50                      → 高层级，确保覆盖其他内容
hidden / flex             → 显示/隐藏控制
sm:static                 → 桌面端改为静态定位
sm:z-auto                 → 桌面端恢复默认层级
sm:flex                   → 桌面端始终显示
inset-s-0                 → 移动端激活时滑入到视口内
```

## 总结

该实现的核心在于：

1. **状态分离**：桌面端和移动端使用独立的状态变量
2. **CSS 定位切换**：移动端用 `absolute` 实现覆盖效果，桌面端用 `static` 实现并排布局
3. **响应式前缀**：通过 `sm:` 前缀区分桌面端和移动端样式
4. **单向切换**：移动端点击列表 → 详情，点击返回 → 列表，桌面端始终并排显示

这种方案不需要路由切换，纯前端状态 + CSS 即可实现，用户体验流畅。
