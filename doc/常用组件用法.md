# 常用组件用法

## 概述

项目组件来自 **shadcn-vue**，基于 **reka-ui**（radix-vue）和 **Tailwind CSS**。组件源码在 `src/components/ui/` 下，可直接修改。

图标来自 **@lucide/vue**，官网：https://lucide.dev/icons/

---

## 表单组件

### Form 表单（VeeValidate + Zod）

```vue
<script setup>
import { toTypedSchema } from '@vee-validate/zod'
import { useForm } from 'vee-validate'
import { z } from 'zod'

const schema = toTypedSchema(z.object({
  name: z.string().min(1, '名称不能为空'),
  email: z.string().email('请输入正确的邮箱'),
}))

const { handleSubmit } = useForm({
  validationSchema: schema,
})

const onSubmit = handleSubmit((values) => {
  console.log(values)
})
</script>

<template>
  <form @submit="onSubmit">
    <FormField v-slot="{ componentField }" name="name">
      <FormItem>
        <FormLabel>名称</FormLabel>
        <FormControl>
          <Input v-bind="componentField" />
        </FormControl>
        <FormMessage />
      </FormItem>
    </FormField>

    <Button type="submit">提交</Button>
  </form>
</template>
```

### Input 输入框

```vue
<!-- 基础用法 -->
<Input v-model="value" placeholder="请输入" />

<!-- 带类型 -->
<Input type="tel" placeholder="手机号" />
<Input type="email" placeholder="邮箱" />

<!-- 禁用 -->
<Input v-model="value" disabled />
```

注意：shadcn-vue 的 Input 内部使用 `useVModel`，绑定用 `v-model` 而不是 `:value`。

### Textarea 文本域

```vue
<Textarea v-model="value" placeholder="请输入备注" />
```

### Select 下拉选择

```vue
<Select v-model="gender">
  <SelectTrigger>
    <SelectValue placeholder="选择性别" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem :value="0">未知</SelectItem>
    <SelectItem :value="1">男</SelectItem>
    <SelectItem :value="2">女</SelectItem>
  </SelectContent>
</Select>
```

### Checkbox 复选框

```vue
<Checkbox v-model="checked" />
```

## 展示组件

### Badge 徽章

```vue
<!-- 基础用法 -->
<Badge>默认</Badge>

<!-- 变体 -->
<Badge variant="secondary">次要</Badge>
<Badge variant="destructive">危险</Badge>
<Badge variant="outline">边框</Badge>

<!-- 自定义扩展的变体 -->
<Badge variant="info">信息</Badge>
<Badge variant="success">成功</Badge>
<Badge variant="warning">警告</Badge>
<Badge variant="gold">金牌</Badge>

<!-- 带图标 -->
<Badge variant="info" class="gap-1">
  <AwardIcon class="size-3" />
  初级
</Badge>
```

### Avatar 头像

```vue
<Avatar class="size-10">
  <AvatarImage :src="avatarUrl" alt="头像" />
  <AvatarFallback>用户</AvatarFallback>
</Avatar>
```

- `AvatarImage`：加载图片，失败自动显示 Fallback
- `AvatarFallback`：图片加载失败或没有 src 时显示

### Card 卡片


### Separator 分隔线

```vue

<Separator orientation="vertical" class="h-4" />
```

## 反馈组件

### Toast 轻提示

```ts
import { toast } from 'vue-sonner'

// 成功
toast.success('操作成功')

// 错误
toast.error('操作失败')

// 普通提示
toast('普通提示')

// 带描述
toast.success('更新成功', {
  description: '您的个人资料已更新'
})
```

### Dialog 对话框

```vue
<script setup>
import { Dialog, DialogContent, DialogHeader, DialogTitle, DialogTrigger } from '@/components/ui/dialog'

const open = ref(false)
</script>

<template>
  <Dialog v-model:open="open">
    <DialogTrigger as-child>
      <Button>打开对话框</Button>
    </DialogTrigger>
    <DialogContent>
      <DialogHeader>
        <DialogTitle>标题</DialogTitle>
      </DialogHeader>
      <div>内容...</div>
    </DialogContent>
  </Dialog>
</template>
```

## 表格组件

### 基础表格

项目使用 `@tanstack/vue-table` 做数据表格。

```vue
<script setup>
import { useVueTable, getCoreRowModel } from '@tanstack/vue-table'

const data = ref([])
const columns = [
  { accessorKey: 'name', header: '姓名' },
  { accessorKey: 'phone', header: '手机号' },
  { accessorKey: 'status', header: '状态' },
]

const table = useVueTable({
  data: data.value,
  columns,
  getCoreRowModel: getCoreRowModel(),
})
</script>
```

具体用法参考项目中的 `src/pages/users/` 或官方文档：https://tanstack.com/table/latest/docs/introduction

## 布局组件

### 页面布局

项目有 3 个布局：

| 布局 | 文件 | 用途 |
|------|------|------|
| default | `layouts/default.vue` | 带侧边栏+顶栏，大部分页面用 |
| blank | `layouts/blank.vue` | 空白，登录注册用 |
| marketing | `layouts/marketing.vue` | 营销页 |

页面中切换布局：

```vue
<route lang="yaml">
meta:
  layout: blank
</route>
```

## 注意事项

1. **组件按需导入** — 不需要全局注册，用到哪个 import 哪个
2. **类名用 Tailwind** — 组件样式基于 Tailwind，自定义用 `class="..."` 覆盖
3. **深色模式自动适配** — 所有组件都支持 dark mode，无需额外处理
