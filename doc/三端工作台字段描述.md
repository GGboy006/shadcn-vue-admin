# 三端工作台字段描述

> 路径前缀：`/residential-web/web`  
> 鉴权：`Authorization: Bearer {token}`  
> 统一响应：`{ code, msg, data }`，成功 `code = 0`  
> 身份参数（partnerId / merchantCode / orgCode）由后端从登录 token 解析，前端可不传  
> 计数字段为 JSON **number**（如 `18`），金额为 number，未就绪字段为 `0` / `[]` / `false`

| 端 | Method | Path | 角色 |
|---|---|---|---|
| 站长 | POST | `/workBench/station` | 站长 |
| 商户/物业 | POST | `/workBench/merchant` | 商户、物业；站长代看可传 `merchantId` |
| 居委会 | POST | `/workBench/neighborhood` | 居委会 |

请求体可空 `{}`。可选字段：

| 字段 | 类型 | 适用 | 说明 |
|---|---|---|---|
| startTime | string | 站长 | 订单统计开始，格式 `yyyy-MM-dd HH:mm:ss`，默认近 30 天 00:00:00 |
| endTime | string | 站长 | 订单统计结束，默认今日 23:59:59 |
| merchantId | number/string | 商户 | 仅站长代看时必传 |

## 一、站长 `data`（stationSummary）

### 1. 概览 Tab

| 字段 | 类型 | 说明 | 口径 |
|---|---|---|---|
| signAnalysis | array | 按签约方类型拆分的签约数量与金额 | 启用主体（status=1），见下表 |
| signTrend | array | 近 6 个月新签约趋势 | 缺月补 0；优先 `signDate`，否则 `createTime` |

**signAnalysis[]**

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | `merchant` 商户 / `org` 居委会 / `property` 物业 |
| typeName | string | 商户 / 居委会 / 物业 |
| count | number | 该类型启用签约数 |
| amount | number | 该类型签约费合计（`signFee`） |

**signTrend[]**

| 字段 | 类型 | 说明 |
|---|---|---|
| month | string | 月份文案，如 `3月` |
| merchant | number | 当月商户新签数 |
| org | number | 当月居委会新签数 |
| property | number | 当月物业新签数 |

### 2. 商户 Tab

| 字段 | 类型 | 说明 | 口径 |
|---|---|---|---|
| totalOrderAmount | number | 区间内商户订单总额 | 默认近 30 天 |
| incomeAnalysis | array | 商户收入排行 | 按订单金额降序 |
| merchantGoodsCount | number | 名下商户商品总数 | |
| merchantFaqCount | number | 名下商户 FAQ 总数 | |
| merchantActivityCount | number | 名下商户活动总数 | |
| orderTrend | array | 近 7 日订单量（本周 vs 上周） | 未就绪返回 `[]` |
| merchantAiConversationCount | number | 商户端 AI 对话次数 | 近 30 天，userTag=商户/物业 |
| merchantAiImageGenerationCount | number | 商户端 AI 生图次数 | 近 30 天 |

**incomeAnalysis[]**

| 字段 | 类型 | 说明 |
|---|---|---|
| merchantCode | string | 商户标识 |
| merchantName | string | 商户名称 |
| totalAmount | number | 区间订单总金额 |
| orderCount | number | 区间订单总笔数 |

**orderTrend[]**（站长、商户共用结构）

| 字段 | 类型 | 说明 |
|---|---|---|
| day | string | 星期，如 `周一` |
| thisWeek | number | 本周当日订单量 |
| lastWeek | number | 上周同期订单量 |

### 3. 小区服务 Tab

| 字段 | 类型 | 说明 |
|---|---|---|
| noticeCount | number | 公告总数 |
| dynamicPendingCount | number | 动态待审数 |
| servicePendingCount | number | 社区服务待启用数 |
| communityGoodsPendingCount | number | 社区商品待启用数 |
| secondhandPendingCount | number | 闲置待审数 |
| feedbackPendingCount | number | 意见反馈待处理数 |
| residentAiConversationCount | number | 居民端 AI 对话次数（近 30 天） |
| residentAiImageGenerationCount | number | 居民端 AI 生图次数（近 30 天） |

### 4. 居委会 Tab

| 字段 | 类型 | 说明 |
|---|---|---|
| leaveMessagePendingCount | number | 名下居委会留言待处理合计 |
| orgAnalysis | array | 名下居委会明细（签约金额 + 留言待处理） |

**orgAnalysis[]**

| 字段 | 类型 | 说明 |
|---|---|---|
| orgCode | string | 居委会标识 |
| orgName | string | 居委会名称 |
| signAmount | number | 该居委会签约金额 |
| leaveMessagePending | number | 该居委会留言待处理数；多居委会拆分未就绪时为 0 |

## 四、未就绪兜底

| 字段 | 当前值 | 原因 |
|---|---|---|
| orderTrend（站长/商户） | `[]` | 等 City Data 按天拆订单量 |
| orgAnalysis[].leaveMessagePending（多个居委会时） | `0` | 等 City Data 按 orgCode 拆分；仅 1 个居委会时会回填汇总值 |
| procurementOrderCount | `0` | 暂无独立智采订单表 |
