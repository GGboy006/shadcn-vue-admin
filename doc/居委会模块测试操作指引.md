# 居委会模块测试操作指引

> 本文档供测试人员对接使用,覆盖居委会后台全部功能模块的操作路径与验证要点。

## 一、进入居委会后台

**入口**:站长后台 -> 左侧菜单「居委会管理」-> 列表中点击某居委会行的名称/操作列「进入居委会后台」

- 自动新窗口打开,进入该居委会的后台
- 首页地址:`/neighborhood/home`

---

## 二、通用交互说明

所有列表页的操作交互统一为:

| 操作 | 交互形式 |
|---|---|
| 新建 | 右上角「新建」按钮 -> 右侧抽屉表单 |
| 编辑 | 行操作 -> 编辑 -> 右侧抽屉表单 |
| 查看 | 行操作 -> 查看 -> 居中弹窗 |
| 删除 | 行操作 -> 删除 -> 二次确认弹窗 |

**响应式**:
- 桌面端:表单/查看为右侧抽屉或居中弹窗
- 移动端:表单/查看为底部抽屉(可向下拖拽关闭),删除为居中确认

**富文本**:活动、公告、资讯等含富文本字段,编辑器支持加粗/斜体/标题/列表/链接/字体颜色/背景色。

## 三、各模块测试要点

### 1. 公告管理(`/neighborhood/notice`)
- 新建/编辑/查看/删除公告
- 字段:标题、简介、正文(富文本/链接两种类型)、公开范围、排序
- 验证:链接类型时显示跳转链接字段;文本类型显示富文本正文

### 2. 活动管理

#### 2.1 活动分类(`/neighborhood/activity-cate`)
- 卡片列表(非表格),新建/编辑/删除
- 字段:分类名称、排序

#### 2.2 活动列表(`/neighborhood/activity`)
- 新建/编辑/查看/删除
- 字段:活动名称、封面图、详情图、主办方、分类、时间、地址、是否收费、价格、推荐、富文本内容
- 列表有封面缩略图列

### 3. 广告管理(`/neighborhood/banner`)
- 新建/编辑/查看/删除
- 字段:广告图、链接、排序、启用状态

### 4. 资讯动态(`/neighborhood/dynamic`)
- 新建/编辑/查看/删除
- 字段:标题、封面图、正文(富文本)、排序
- 列表有封面缩略图列

### 5. 服务管理

#### 5.1 栏目管理(`/neighborhood/unified`)
- 新建/编辑/查看/删除
- 字段:栏目名称、内容(富文本)、排序

#### 5.2 专题管理(`/neighborhood/special`)
- 新建/编辑/删除(无查看)
- 字段:专题名称、排序

#### 5.3 专题文章(`/neighborhood/special/{code}/article`)
- 从专题管理点击名称进入
- 新建/编辑/查看/删除
- 字段:文章标题、封面图、正文(富文本)、排序
- 列表有封面缩略图列

### 6. 居委会信息(`/neighborhood/org-info`)
- 居委会基础信息编辑(单条,无列表)
- 字段:居委会名称、地址、联系电话、服务居民数、成员信息等

### 7. 服务热线(`/neighborhood/service-guide`)
- 卡片列表(非表格)
- 每张卡片:服务名称、电话(带电话图标)、复制按钮(点击复制手机号)
- 新建/编辑/删除
- 验证:点复制按钮能复制手机号到剪贴板

### 8. 在线留言(`/neighborhood/leave-message`)
- 仅列表 + 查看(无新建/编辑/删除)
- 行操作是「眼睛」图标,点击直接打开详情弹窗
- 字段:留言人、联系方式、留言内容、留言时间

### 9. 居委会服务(`/neighborhood/service`)
- 新建/编辑/查看/删除
- 字段:服务名称、服务内容(富文本)、排序

---

## 四、列表查询能力

### 分页表格(9 个)
公告、活动列表、广告、资讯动态、栏目、专题、专题文章、居委会服务、在线留言

- **分页**:均支持,底部翻页 + 每页条数切换
- **关键字搜索**:均支持,输入框防抖 300ms 自动搜索,搜索后自动回到第 1 页

### 卡片列表(2 个,全量加载)
- **活动分类**(`/neighborhood/activity-cate`):一次拉全量(pageSize=99),无分页、无搜索
- **服务热线**(`/neighborhood/service-guide`):同上,全量加载
