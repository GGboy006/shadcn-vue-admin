## 一、接口清单(4 个,标准 CRUD,无 detail)

| # | 函数 | 方法 | 路径 | 用途 |
|---|------|------|------|------|
| 1 | `useGetServiceGuidePageQuery` | GET | `/community/serviceGuide/page` | 分页列表(`keyword` 模糊搜索) |
| 2 | `useCreateServiceGuideMutation` | POST | `/community/serviceGuide` | 新增 |
| 3 | `useUpdateServiceGuideMutation` | PUT | `/community/serviceGuide` | 更新 |
| 4 | `useDeleteServiceGuideMutation` | DELETE | `/community/serviceGuide/{uniqueCode}` | 删除(按 uniqueCode) |

**API 文件**:`src/services/api/community-service-guide.api.ts`(已生成)

### 关键特性

- **无独立 detail 接口**:编辑回填 + 查看详情都用列表行数据(列表返回即全字段)
- **无 parentList 接口**:父子结构不启用(见方案决策)

## 二、方案决策(已拍板)

| 决策项 | 结论 | 说明 |
|--------|------|------|
| **type 字段** | **前端不用** | 去掉 type 枚举,列表不显示、表单不填、请求不传。API 文件保留字段定义(后端可能仍需) |
| **父子结构** | **不启用** | `parentCode` 前端不用,列表不展示、表单不填、请求不传。字段保留在 API 文件 |
| **三大长文本** | **Textarea** | `acceptanceConditions`/`applicationMaterials`/`handlingProcedures` 用 `<Textarea>` 纯文本编辑 |
| **页面形态** | **传统扁平列表** | 标准 A 类模式:表格 + 行操作(查看/编辑/删除),套用 column/cate/service/phone-list 模板 |

## 三、数据模型(标注前端使用范围)

### 3.1 VO 字段使用范围

| 字段 | 类型 | 前端 | 说明 |
|------|------|------|------|
| `id` | number | ❌ 不用 | 主键(后端用) |
| `uniqueCode` | string | ✅ 读写 | 增删改主键 |
| `parentCode` | string? | ❌ 不用 | 父子结构废弃 |
| `title` | string | ✅ 读写 | 标题(**必填**) |
| `type` | 1\|2\|3\|4? | ❌ 不用 | 去掉 type |
| `poster` | string? | ✅ 读写 | 封面图(上传) |
| `unit` | string? | ✅ 读写 | 单位 |
| `address` | string? | ✅ 读写 | 地址 |
| `phone` | string? | ✅ 读写 | 电话 |
| `describe` | string? | ✅ 读写 | 描述(Textarea) |
| `worktime` | string? | ✅ 读写 | 工作时间 |
| `acceptanceConditions` | string? | ✅ 读写 | 受理条件(**Textarea**) |
| `applicationMaterials` | string? | ✅ 读写 | 申请材料(**Textarea**) |
| `handlingProcedures` | string? | ✅ 读写 | 办理流程(**Textarea**) |
| `isEnable` | 1\|2? | ✅ 读写 | 启用状态(默认 1) |
| `regionName` | string? | 📖 只读 | 区域名(详情展示) |
| `partnerId` | string? | ❌ 不用 | 后端填充 |
| `partnerPid` | string? | ❌ 不用 | 后端填充 |
| `createTime` | string? | 📖 只读 | 列表+详情展示 |
| `operatorTime` | string? | 📖 只读 | 详情展示 |

### 3.2 请求体(前端实际传输字段)

```ts
// AddDTO / UpdateDTO 前端实际传的字段(裁剪后)
{
  title: string              // 必填
  poster?: string
  unit?: string
  address?: string
  phone?: string
  describe?: string
  worktime?: string
  acceptanceConditions?: string
  applicationMaterials?: string
  handlingProcedures?: string
  isEnable?: 1 | 2
  // UpdateDTO 额外:uniqueCode
}
```

> 注:`type`/`parentCode`/`partnerId`/`partnerPid` 等前端不传,后端自行处理。API 文件的 DTO 类型保留全字段(向后兼容),前端表单按上表裁剪。

### 3.3 枚举(仅保留启用状态)

- `isEnable`:1=启用 / 2=禁用
- ~~`type` 枚举~~:前端不用,`serviceGuideTypeConfig` 不引用

## 四、实现要点

### 4.1 文件结构(套用 A 类模式,11 个文件)

```
src/pages/community/guide/
├── index.vue                              # 入口页
├── components/
│   ├── columns.ts                         # 列定义
│   ├── data-table.vue                     # 表格容器
│   ├── data-table-toolbar.vue             # 搜索 + 列显隐
│   ├── data-table-row-actions.vue         # 行操作(查看/编辑/删除)
│   ├── guide-form.vue                     # 表单(含 3 个 Textarea)
│   ├── guide-form-sheet.vue              # 编辑/新建 Sheet

│   ├── guide-detail-dialog.vue           # 查看 Modal
│   └── guide-delete-dialog.vue           # 删除 AlertDialog
```

### 4.2 列表列定义(columns.ts)

建议列(扁平列表,无 type 列、无父级列):

| 列 | 字段 | 说明 |
|----|------|------|
| 选择框 | - | SelectColumn |
| 封面 | `poster` | 缩略图(同 column/phone-list) |
| 标题 | `title` | 主字段,truncate |
| 单位 | `unit` | - |
| 电话 | `phone` | 可加 `PropPiCopy` 复制图标(同 phone-list 联系电话) |
| 状态 | `isEnable` | Badge(启用/禁用) |
| 创建时间 | `createTime` | - |
| 操作 | - | 行操作 |

### 4.3 表单字段(guide-form.vue)

| 字段 | 组件 | 必填 | 备注 |
|------|------|------|------|
| 标题 | `Input` | ✅ | - |
| 封面图 | `useUpload` | - | 单图上传(同 column) |
| 单位 | `Input` | - | - |
| 地址 | `Input` | - | - |
| 电话 | `Input` | - | - |
| 工作时间 | `Input` | - | 如「周一至周五 9:00-18:00」 |
| 描述 | `Textarea` | - | `rows="2"` |
| 受理条件 | `Textarea` | - | `rows="4"`(长文本) |
| 申请材料 | `Textarea` | - | `rows="4"`(长文本) |
| 办理流程 | `Textarea` | - | `rows="4"`(长文本) |
| 启用状态 | `Select` | - | 默认 1 |

> Textarea 引用:`import { Textarea } from '@/components/ui/textarea'`,写法参考 `service-form.vue` 的 `describe` 字段。

### 4.4 详情 Modal(guide-detail-dialog.vue)

按区块展示(参考 phone-list 详情的分组思路):
- 头部:封面图 + 标题 + 状态 Badge
- 基础信息:单位 / 地址 / 电话 / 工作时间 / 区域名(只读)
- 描述:describe
- 受理条件 / 申请材料 / 办理流程:三个长文本区块(支持换行渲染,用 `whitespace-pre-wrap`)
- 元信息:创建时间 / 更新时间

### 4.5 校验(guide.validator.ts)

```ts
import { z } from 'zod'
import { optionalNumber, optionalString } from '@/validators/common'

export const communityServiceGuideValidator = z.object({
  uniqueCode: optionalString,
  title: z.string().min(1, '标题不能为空'),
  poster: optionalString,
  unit: optionalString,
  address: optionalString,
  phone: optionalString,
  describe: optionalString,
  worktime: optionalString,
  acceptanceConditions: optionalString,
  applicationMaterials: optionalString,
  handlingProcedures: optionalString,
  isEnable: optionalNumber,
})

export type CommunityServiceGuideValidator = z.infer<typeof communityServiceGuideValidator>
```
