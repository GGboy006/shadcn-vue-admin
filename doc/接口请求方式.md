# 接口请求方式

## 概述

项目使用 **ofetch**（Nuxt 团队封装的 fetch）作为 HTTP 客户端，通过 `useApiFetch` 组合函数提供预配置好的请求实例。

```ts
import { useApiFetch } from '@/composables/use-fetch'

const { apiFetch } = useApiFetch()
```

后端接口约定：

- `code === 0`：请求成功
- `code === 30002`：未授权（token 过期）
- 其他 code：业务错误

---

## 简单请求

### GET 请求

```ts
const { apiFetch } = useApiFetch()

// 无参数
const res = await apiFetch('/station/myStationInfo')
console.log(res.data)

// 带查询参数
const res = await apiFetch('/users', {
  query: { page: 1, size: 10 }
})
```

### POST 请求

```ts
const res = await apiFetch('/login/password', {
  method: 'POST',
  body: { phone: '13800138000', password: '123456' }
})
```

### PUT 请求

```ts
await apiFetch('/station/updateStationInfo', {
  method: 'PUT',
  body: {
    stationId: 1,
    stationName: '永顺社区一号站',
  }
})
```

### DELETE 请求

```ts
await apiFetch(`/users/${userId}`, {
  method: 'DELETE'
})
```

## 错误处理

`apiFetch` 已封装好统一错误处理：**非 0 的 code 会自动抛出异常**。

调用方只需要写成功逻辑：

```ts
// ✅ 正确：只处理成功
const res = await apiFetch('/station/myStationInfo')
// 到这里说明 code === 0，直接用 res.data
userInfoStore.setStationInfo(res.data)
```

不需要在每次请求后判断 `if (res.code === 0)`，拦截器已经处理好了。

### 需要特殊处理错误时

```ts
try {
  const res = await apiFetch('/some-api')
  // 成功逻辑
}
catch {
  // 可选：补充处理
  // 注意：拦截器已经 toast 了通用错误，这里只做额外操作
}
```

## 复杂请求：表格分页列表

### 带分页、搜索、排序的表格请求

```ts
import { useApiFetch } from '@/composables/use-fetch'

const { apiFetch } = useApiFetch()

// 查询参数
const searchParams = ref({
  keyword: '',
  status: undefined as number | undefined,
})

const pagination = ref({
  page: 1,
  size: 10,
  total: 0,
})

// 获取列表
async function fetchList() {
  const res = await apiFetch('/users/list', {
    query: {
      page: pagination.value.page,
      size: pagination.value.size,
      keyword: searchParams.value.keyword || undefined,
      status: searchParams.value.status,
    }
  })

  pagination.value.total = res.data.total
  return res.data.list
}

// 搜索（重置到第一页）
function handleSearch() {
  pagination.value.page = 1
  fetchList()
}

// 翻页
function handlePageChange(page: number) {
  pagination.value.page = page
  fetchList()
}
```

### 配合加载状态

```ts
const loading = ref(false)
const list = ref<any[]>([])

async function fetchList() {
  loading.value = true
  try {
    const res = await apiFetch('/users/list', {
      query: { page: pagination.value.page, size: pagination.value.size }
    })
    list.value = res.data.list
    pagination.value.total = res.data.total
  }
  finally {
    loading.value = false
  }
}
```

## 文件上传

项目已封装 `useUpload` 组合函数：

```ts
import { useUpload } from '@/composables/use-upload'

const { upload, loading } = useUpload()

// 在 input change 事件中调用
async function handleFileChange(event: Event) {
  const file = (event.target as HTMLInputElement).files?.[0]
  if (!file)
    return

  const url = await upload(file)
  // url 是上传后的文件地址
  console.log(url)
}
```

模板中使用：

```vue
<label class="cursor-pointer">
  {{ loading ? '上传中...' : '上传文件' }}
  <input type="file" class="sr-only" @change="handleFileChange">
</label>
```

## useApiFetch 配置

### 全局配置位置

`src/composables/use-fetch.ts`

已配置项：

| 配置    | 说明                                                  |
| ------- | ----------------------------------------------------- |
| baseURL | 从 `.env` 读取 `VITE_SERVER_API_URL`                  |
| timeout | 从 `.env` 读取 `VITE_SERVER_API_TIMEOUT`，默认 5000ms |
| headers | 自动附加 `Authorization: Bearer ${token}`             |
| 拦截器  | 统一处理 code !== 0 的错误，30002 时清除登录态        |

### 本地开发代理

`vite.config.ts` 中无需配置 proxy，请求直接发到 `VITE_SERVER_API_URL` 指定的地址。

## 什么时候用 TanStack Query

项目已安装 `@tanstack/vue-query`，但简单场景建议直接用 `apiFetch`：

| 场景                             | 推荐方式                              |
| -------------------------------- | ------------------------------------- |
| 一次性请求（提交表单、获取详情） | `apiFetch`                            |
| 列表页（带分页、搜索）           | `apiFetch` + 手动管理状态             |
| 需要缓存、自动刷新、乐观更新     | TanStack Query                        |
| 多个关联请求有依赖关系           | TanStack Query `useQuery` + `enabled` |

### TanStack Query 简单用法

```ts
import { useQuery } from '@tanstack/vue-query'

const { data, isLoading } = useQuery({
  queryKey: ['stationInfo'],
  queryFn: async () => {
    const res = await apiFetch('/station/myStationInfo')
    return res.data
  }
})
```

## 接口路径速查

| 功能          | 接口                         | 方法    |
| ------------- | ---------------------------- | ------- |
| 登录          | `/login/password`            | POST    |
| 退出登录      | `/login/logout`              | POST    |
| 当前用户信息  | `/login/current`             | PUT/GET |
| 站长信息      | `/station/myStationInfo`     | GET     |
| 更新站长信息  | `/station/updateStationInfo` | PUT     |
| 商户/物业信息 | `/merchant/myMerchantInfo`   | GET     |
| 文件上传      | `/file/upload`               | POST    |

---

## 注意事项

1. **不用 axios** — 项目使用 ofetch，API 和 axios 不同（如 `query` 而不是 `params`）
2. **不用重复判断 code** — 拦截器已处理，直接 `await apiFetch(...)` 后取 `res.data`
3. **body 自动序列化** — 传对象即可，`ofetch` 会自动 `JSON.stringify`
4. **文件上传用 useUpload** — 不要直接用 `apiFetch` 传文件
