# 菜单结构

## 概述

项目菜单分为两部分：

1. **侧边栏主菜单**（`src/composables/use-sidebar.ts`）
2. **设置页面子菜单**（`src/composables/use-sidebar.ts` 中的 `settingsNavItems`）

菜单渲染组件：`src/components/app-sidebar/`

---

## 菜单配置位置

```ts
// src/composables/use-sidebar.ts

export function useSidebar() {
  const authStore = useAuthStore()
  const userType = authStore.getUserType() // 获取当前用户类型

  // 设置页面子菜单
  const allSettingsNavItems = [
    { title: '个人资料', url: '/settings/', icon: UserIcon },
    { title: '站长信息', url: '/settings/account', icon: WrenchIcon, roles: [3] },
  ]

  // 根据角色过滤设置菜单
  const settingsNavItems = allSettingsNavItems.filter((item) => {
    if (!item.roles)
      return true
    return userType !== undefined && item.roles.includes(userType)
  })

  // 主菜单
  const navData = ref<NavGroup[]>([
    {
      title: '通用',
      items: [
        { title: '仪表盘', url: '/dashboard', icon: LayoutDashboardIcon },
        { title: '任务', url: '/tasks', icon: ListTodoIcon },
        { title: '应用', url: '/apps', icon: BoxesIcon },
        { title: '用户', url: '/users', icon: UsersIcon },
      ],
    },
    {
      title: '其他',
      items: [
        { title: '设置', items: settingsNavItems, icon: SettingsIcon },
      ],
    },
  ])

  return { navData, settingsNavItems }
}
```

## 菜单项结构

### 普通菜单项

```ts
{
  title: '仪表盘',      // 显示名称
  url: '/dashboard',    // 跳转路径
  icon: LayoutDashboardIcon,  // 图标（来自 @lucide/vue）
}
```

### 带子菜单的分组

```ts
{
  title: '认证',
  icon: SquareUserRoundIcon,
  items: [
    { title: '登录', url: '/auth/sign-in' },
    { title: '注册', url: '/auth/sign-up' },
  ],
}
```

### 带角色权限的菜单项

```ts
{
  title: '站长信息',
  url: '/settings/account',
  icon: WrenchIcon,
  roles: [3],  // 只有 userType === 3 的用户能看到
}
```

| roles 值 | 含义           |
| -------- | -------------- |
| 无       | 所有人可见     |
| `[3]`    | 仅站长可见     |
| `[3, 4]` | 站长和商户可见 |
| `[4, 5]` | 商户和物业可见 |

---

## 路由与菜单的关系

菜单是 UI 层的展示控制，**不阻止直接访问 URL**。

例如：商户（userType=4）看不到"站长信息"菜单，但如果手动输入 `/settings/account`：

- 菜单层：不显示（已过滤）
- 路由层：被守卫拦截，跳转到 403 页面

路由守卫角色判断见 `src/router/guard/auth-guard.ts`。

## 如何新增菜单

### 1. 新增主菜单项

在 `navData` 的对应分组 `items` 中添加：

```ts
{
  title: '新页面',
  url: '/new-page',
  icon: SomeIcon,  // 从 @lucide/vue 导入
}
```

然后在 `src/pages/` 下创建对应文件：`src/pages/new-page/index.vue`

### 2. 新增设置子菜单项

在 `allSettingsNavItems` 中添加：

```ts
{
  title: '新设置',
  url: '/settings/new',
  icon: SomeIcon,
  roles: [3],  // 可选：限制特定角色
}
```

然后创建页面：`src/pages/settings/new.vue`

### 3. 新增带角色的菜单

```ts
{
  title: '站长专属功能',
  url: '/station-only',
  icon: WrenchIcon,
  roles: [3],
}
```

同时在页面文件顶部加路由守卫标记：

```vue
<!-- src/pages/station-only/index.vue -->
<route lang="yaml">
meta:
  roles: [3]
</route>
```

## 图标来源

所有图标来自 `@lucide/vue`，官网：https://lucide.dev/icons/

使用方式：

```ts
import { LayoutDashboardIcon, UserIcon } from '@lucide/vue'
```

菜单中使用的图标需要在这行导入：

```ts
// src/composables/use-sidebar.ts 第 1 行
import { ... } from '@lucide/vue'
```
